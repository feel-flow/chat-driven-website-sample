# cost-calculation.md — コスト試算

書籍 **付録 F「コスト試算」** の元データです。

「外注なし・コスト 1/100」を実証するため、本書スタックで小規模ビジネスサイト（月間 PV 〜10,000）を運用した場合の月額コストを、外注見積もり相場と比較します。

> **注記**: 価格は 2026 年 5 月時点のものです。各サービスは価格改定があるため、本番運用前に各公式ページで最新料金を確認してください。

---

## 1. 比較サマリ

| 項目 | 外注（一般的な相場） | 本書スタック |
|------|-------------------|------------|
| **初期構築** | 50〜200 万円 | 0 円（テンプレ流用） |
| **月額運用費（インフラ）** | 5,000〜30,000 円 | **0〜500 円**（Hobby/Free 枠内） |
| **月額運用費（更新作業代行）** | 30,000〜100,000 円 | **0〜2,000 円**（AI API 利用料のみ） |
| **更新リードタイム** | 数日〜2 週間 | 5 秒〜10 分 |
| **年間総額（運用のみ）** | **42〜156 万円** | **0〜3 万円** |

ざっくり **コスト比 1/50 〜 1/100**、リードタイム比 **1/100 〜 1/1000** という構図になります。

## 2. 外注見積もりの相場（参考）

中小企業向けコーポレートサイト（10〜20 ページ規模）の一般的な相場:

| 項目 | 相場 | 出典・備考 |
|------|------|----------|
| 初期構築（デザイン + 実装） | 50〜200 万円 | 中小規模制作会社の標準的見積もりレンジ |
| 月額保守（軽微な更新含む） | 5,000〜30,000 円 | サーバ管理・SSL 更新等の基本保守 |
| 記事 1 本追加（外注ライター込み） | 10,000〜30,000 円 | 1,500〜3,000 字、SEO 調整あり |
| サービスページ追加 | 30,000〜80,000 円 | デザイン調整 + ライティング |
| SEO コンサル | 月 30,000〜200,000 円 | 内部最適化 + キーワード設計 + レポート |

> **出典**: 上記は中小企業向け Web 制作会社が公開している標準パッケージの一般的なレンジを参考にしています。具体的な金額は会社規模・対応範囲によって大きく変動するため、複数社から見積もりを取って比較するのが基本です。

ニュース月 2 本 + サービスページ年 4 本 + 月次保守の場合、年間 **42〜156 万円** が目安。

## 3. 本書スタックの月額試算

### 3-1. Vercel（ホスティング・サーバレス）

| プラン | 月額 | 主な制限 | 本書スタックでの妥当性 |
|--------|------|--------|-------------------|
| **Hobby** | 0 円 | 100 GB 帯域 / 月、商用利用不可 | 個人ブログ・PoC 向け |
| **Pro** | 約 3,000 円（$20/月） | 1 TB 帯域、商用 OK | 中小企業の本番サイト推奨 |

中小企業のコーポレートサイト（月間 PV 〜10,000、画像中心）であれば、Pro プランで十分に運用できます。Hobby プランは個人利用・PoC 限定です。

> **出典**: [Vercel Pricing](https://vercel.com/pricing) — Hobby / Pro プランの公式ページを参照。為替レートにより日本円換算は変動します。

### 3-2. Resend（メール送信）

| プラン | 月額 | 主な制限 |
|--------|------|--------|
| **Free** | 0 円 | 月 3,000 通、独自ドメイン送信可 |
| **Pro** | 約 3,000 円（$20/月） | 月 50,000 通 |

お問い合わせフォーム経由のメールが月 100 件以下であれば、Free プランで完全カバーできます。

> **出典**: [Resend Pricing](https://resend.com/pricing)。

### 3-3. Cloudflare Turnstile（スパム対策）

| プラン | 月額 |
|--------|------|
| **無料** | 0 円（リクエスト数無制限） |

Turnstile は商用利用も含めて完全無料です。

> **出典**: [Cloudflare Turnstile](https://www.cloudflare.com/products/turnstile/) — 無料 CAPTCHA 代替サービス。

### 3-4. 独自ドメイン

| 種類 | 年額 | 月額換算 |
|------|------|--------|
| `.com` / `.net` | 約 1,500〜3,000 円 | 約 125〜250 円 |
| `.jp` | 約 3,000〜5,000 円 | 約 250〜420 円 |
| `.co.jp` | 約 4,000〜7,000 円 | 約 330〜580 円 |

> **出典**: [お名前.com](https://www.onamae.com/) / [ムームードメイン](https://muumuu-domain.com/) の標準価格レンジ。レジストラ・キャンペーンにより変動します。

### 3-5. AI API（Codex / Claude）の利用料

更新作業を AI に任せる際の API 利用料です。

| 想定利用 | 月額目安 |
|---------|--------|
| ニュース 2 本 / 月 + サービスページ 1 本 / 月（個人プラン） | 数百円〜2,000 円程度 |
| 上記 + SEO レビュー数回 | 1,000〜3,000 円程度 |
| Claude Pro / Codex 個人プラン定額利用 | 約 3,000 円〜（$20/月） |

> **出典・前提**: OpenAI / Anthropic の API は従量課金、Claude Pro / Codex の個人プランは月額定額。価格・トークンレートは頻繁に改定されるため、[OpenAI API Pricing](https://openai.com/api/pricing/) / [Anthropic Pricing](https://www.anthropic.com/pricing) で最新値を確認してください。
>
> 上記は「ニュース 1 本あたり 5,000〜20,000 トークン」「サービスページ 1 本あたり 10,000〜30,000 トークン」「SEO レビュー 1 回あたり 3,000〜10,000 トークン」程度を想定した概算です。プロンプトの長さ・モデル選択（Sonnet / Opus / GPT 系統）で大きく変わります。

### 3-6. 合計（月額）

| プラン構成 | 月額合計 | 用途 |
|----------|--------|------|
| **最小構成**（Vercel Hobby + Resend Free + .com + AI 数百円） | 約 200〜500 円 | 個人ブログ・小規模 PoC |
| **標準構成**（Vercel Pro + Resend Free + .com + AI 個人定額） | 約 6,000〜8,000 円（AI 定額のみ前提、追加従量なし） | 中小企業の本番サイト |
| **拡張構成**（Vercel Pro + Resend Pro + .jp + AI 重め） | 約 10,000〜15,000 円 | 月間 PV 数万・大量配信 |

年間 **2,400 円〜18 万円** で運用できます。

## 4. 外注 vs 本書スタックの比較（年額）

| 項目 | 外注 | 本書スタック（標準） |
|------|------|------------------|
| 初期構築 | 100 万円（中央値） | 0 円 |
| 月額保守 × 12 | 18 万円 | 7 万円 |
| 記事・サービスページ追加（年 16 本） | 32 万円 | 含む（AI 定額内） |
| SEO コンサル × 12 | 60 万円 | 0 円（`/seo-review` で内製） |
| **年額合計** | **約 210 万円** | **約 7 万円** |
| **比率** | — | **約 1/30** |

初期構築を償却込みで考えると、外注の年間 TCO は約 100〜200 万円、本書スタックは **約 5〜10 万円**。コスト比は **1/20 〜 1/40 程度** が現実的な目安です。書籍タイトルの「コスト 1/100」は AI API の使い方を絞った場合や、外注をフルパッケージで契約していた場合の上限値として扱ってください。

## 5. 数字の使い方（注意）

- 上記はあくまで **目安** です。実際の利用量・契約プラン・為替で大きく変動します
- 外注見積もりは制作会社の規模・地域・スコープによって 50% 以上ぶれます
- Vercel の Hobby プランは **商用利用不可** です。中小企業の本番サイトは Pro プラン以上を選択してください
- AI API 利用料は **プロンプトと出力の合計トークン数** に比例します。長文記事・大量画像生成を行う場合は別途試算してください
