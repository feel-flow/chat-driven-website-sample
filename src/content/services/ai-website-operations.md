ホームページを公開したあと、更新が担当者の空き時間に依存して止まってしまう企業様向けの伴走サービスです。
Codex と Vercel Deploy Preview を使い、依頼から確認、公開までを小さな PR 単位で回せる状態を作ります。

## こんな方におすすめ

- ニュースや事例の更新が数か月止まっている
- 制作会社に軽微な修正を頼むたびに費用と待ち時間が発生している
- AI を導入したいが、社内でどの手順から始めるべきか決めきれない
- Web 担当者がレビューしやすい PR 運用を整えたい

## 主な支援メニュー

- **運用フロー設計**: ニュース追加、サービス更新、SEO レビューの標準手順を整理
- **Skills 整備**: 社内の依頼文に合わせた Codex / Claude Code 用の手順書を作成
- **初回デモ伴走**: 実際の更新 1〜3 件を PR 化し、確認から公開まで一緒に実施
- **レビュー定着**: `pnpm verify`、Deploy Preview、差分確認を担当者が読める形に整備

## 標準プラン

| プラン | 期間 | 内容 |
|--------|------|------|
| 初回診断 | 30 分 | 現状の更新フローと課題を整理 |
| 運用設計 | 2 週間 | 更新ルール、Skills、PR 確認手順を作成 |
| 定着伴走 | 1〜2 ヶ月 | 月次の更新実行とレビュー改善を支援 |
