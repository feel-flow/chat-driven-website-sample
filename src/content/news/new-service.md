このたび、新しいサービスとして「AI コンサルティング」を開始しました。

Codex や Claude Code を業務に組み込みたいが、何から始めればよいか分からない企業様向けに、初期設計から運用ワークフロー定着までを伴走支援します。

## 想定するご相談例

- ホームページ運用を AI で効率化したい
- 社内ドキュメントの整備を AI に任せたい
- 営業メールやレポートの下書きを AI で自動化したい
- エンジニア組織に Claude Code を導入したい

## ご相談の流れ

1. **無料相談（30 分）** で現状ヒアリング
2. **PoC 提案** で 2〜4 週間の試験導入
3. **本格導入支援** で運用フローを社内に定着

詳細は [サービスページ](/services/ai-consulting) をご覧ください。
